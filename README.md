# Full Stack Monorepo

## 目录
- `backend/`: 当前 NestJS 后端
- `apps/liberty-web`: Next.js H5 应用
- `apps/liberty-ui`: UmiJS Admin 应用
- `packages/`: 预留给共享类型、工具函数、UI 组件
- `docs/`: 项目文档和迁移记录

## 常用命令
- `pnpm --dir backend install`
- `pnpm dev:backend`
- `pnpm dev:web`
- `pnpm dev:ui`
- `pnpm build:backend`
- `pnpm build:web`
- `pnpm build:ui`
