## 1. 登录体系决策

### 1.1 注册方式
- [x] 是否允许仅用 `username + password` 注册
- [x] 是否要求注册时必须提供 `email`
- [x] 是否要求注册时必须提供 `phone`
- [x] 是否允许后续补充邮箱或手机号
- [x] 用户名是否允许修改

建议默认：
- 一期允许 `username + password` 注册
- `email`、`phone` 先设为可选
- 用户名注册后不可修改，减少身份歧义

最终决策：
- 允许 `username + password` 注册，但用户端 H5 注册能力需要支持开关控制，由 `system_settings.public_user_register_enabled` 管理
- 系统不引入 `email`，注册时不要求提供 `email`
- `phone` 默认非必填，但需要支持“注册时必须填写手机号”的开关，并在 `.env.example` 中说明
- 允许用户在注册后补充手机号
- `username` 注册后不允许修改
- 需要额外提供可展示的外显名称字段，用于替代用户名展示

决策日期：
- 2026-04-27

### 1.2 登录账号标识
- [ ] 登录时是否只支持 `username`
- [x] 是否支持 `username / phone` 登录
- [x] 不支持 `email` 登录

建议默认：
- 一期支持 `username / phone` 统一 `account` 字段登录
- 不引入 `email` 登录，减少歧义与额外校验成本

最终决策：
- 登录仅支持 `username` 与 `phone`

决策日期：
- 2026-04-24

### 1.3 密码规则
- [x] 密码最小长度是否定为 `8`
- [x] 是否要求大小写、数字、特殊字符组合
- [x] 是否允许弱密码但给出风险提示
- [x] 是否需要密码过期机制

建议默认：
- 一期最小长度 `8`
- 不强制复杂组合，但不允许过弱密码
- 不做密码过期机制

最终决策：
- 密码最小长度固定为 `8`
- 复杂度最低要求为“至少包含字母与数字”
- 不强制要求大写字母、小写字母、特殊字符同时出现
- 一期不单独放行“弱密码但仅提示风险”的模式，按最低校验规则直接拦截
- 不做密码过期机制

决策日期：
- 2026-04-27

- 活跃 session 以单登录态为主，减少状态复杂度

最终决策：

决策日期：
- 2026-04-24

- access token 与 refresh token 生命周期均需支持环境变量动态配置，并在 `.env.example` 中说明

## 3. 用户与管理员决策

### 3.1 管理员能力边界
- [x] 管理员是否可以查看所有用户会话
- [x] 管理员是否可以踢指定设备
- [x] 管理员是否可以强制全部下线
- [x] 管理员是否可以查看审计日志

建议默认：
- 一期全部支持，但日志查看能力可延后到二期

最终决策：
- 管理员可以查看所有用户会话
- 后台按角色权限控制，角色分为：`超级管理员（全部）`、`管理员`、`用户`
- 由于系统最终决策为“不允许多端同时登录”，因此同一用户同一时刻仅存在一个有效登录会话
- 基于单登录策略，不存在“踢指定设备”或“某用户多个设备全部下线”的实际业务场景
- 后台不提供按单个设备下线能力；如需下线，仅按当前唯一有效会话处理
- 后台支持对因频繁登录被冻结的账号进行手动解封
- 管理员可以查看审计日志
- 需要支持管理员查看用户登录历史
- 登录历史建议与审计日志分开定义保留策略：登录历史保留最近 `15d`

决策日期：
- 2026-04-27

## 4. 会话管理决策

- 会话信息中保留并展示当前唯一有效会话的最后活跃时间

- 2026-04-27

### 4.2 下线策略
- [x] 用户是否可以下线当前设备之外的任意设备
- [x] 用户执行“全部下线”时，当前设备是否也一起失效
- [x] 管理员强制下线后，前端是否需要明确错误提示文案

建议默认：
- 用户可下线自己名下任意设备
- 全部下线包含当前设备
- 前端应提示“账号已在其他位置被退出或被管理员下线”

最终决策：
- 用户执行“全部下线”时，当前设备也一起失效
- 由于不允许多端同时登录，不存在“当前设备之外的其他在线设备”可供下线
- 普通用户不提供按设备下线功能，仅保留“全部下线（即退出当前唯一会话）”能力
- 后台也不提供按设备下线功能；如需强制下线，仅处理当前唯一有效会话
- 管理员强制下线后的前端提示文案支持动态配置，并在 `.env.example` 中说明
- 若未配置自定义文案，则使用默认提示：`用户信息已过期，请重新登录！`

- 2026-04-27

- 冻结时长与失败阈值均需支持环境变量动态配置，并在 `.env.example` 中说明
- 后台支持手动解封被冻结账号
